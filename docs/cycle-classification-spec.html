1. Overview

Ritu classifies each user as Regular, Variable, or Unpredictable based on how much their recent cycle lengths deviate from their own average — not against a fixed reference value such as 28 days. A cycle length is defined as the number of days between two consecutive logged period start dates.

2. Calculation Steps

StepDescription
1. Select the sample Requires a minimum of 3 completed cycles before classification is attempted. For a new user, the sample grows with each logged cycle — 3, then 4, then 5 — until 6 cycles have been logged. From that point on, use a rolling window of the 6 most recent completed cycles, dropping the oldest as each new one is logged, so a user's classification can continue to change over time in either direction.
2. Compute the mean Sum the 6 cycle lengths and divide by 6. This produces the user's own personal average, not a fixed assumption.
3. Compute per-cycle deviation For each of the 6 cycles, compute the absolute difference between that cycle's length and the mean from step 2. Direction (shorter or longer) is not considered — only magnitude.
4. Compute Mean Absolute Deviation (MAD) Average the 6 absolute deviations from step 3. This single value, referred to as MAD throughout this document, is the sole input to classification.
5. Apply thresholds Compare MAD against the three bands defined in Section 3 to determine classification.

3. Classification Thresholds

MAD (days)Classification
0–4Regular
5–9Variable
10+Unpredictable
Minimum data requirement: Classification requires at least 3 completed cycles, which in turn requires at least 4 logged period start dates (a cycle length is only defined between two consecutive start dates). Below this threshold, the user remains Unclassified.

5. Design Rationale

Deviation is measured against the user's own mean, not a fixed reference value

A user whose cycles consistently run 35 days is exactly as regular as a user whose cycles consistently run 28 days. Classification measures consistency relative to the individual, not conformity to a textbook value.

The sample window is 6 cycles, not the user's full history or a minimum of 3

A rolling window reflects a user's recent pattern rather than a lifetime average. If a user's cycle regularity genuinely changes over time, this allows their classification to update accordingly rather than remaining fixed to data from years prior.

Deviations are averaged, not reduced to a single largest value

A single atypical cycle (attributable to travel, illness, or stress) should not by itself determine classification. Averaging all 6 deviations ensures one outlier is smoothed into the result rather than dominating it.
